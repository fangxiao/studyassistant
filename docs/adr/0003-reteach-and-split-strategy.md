# ADR-0003: 未达标时先「换角度重讲」，多次无效则「降级拆解」

- 状态: 已接受
- 日期: 2026-09-28
- 决策者: 用户（需求确认）+ AI 研发伙伴

## 背景

需求原文：「没学会的继续讲知识点**直到你学会为止**」。

这句话如果直译成「循环重讲同一段内容」，会产生两个失败模式：

1. **无效重复** —— 把同样的话再说一遍，学习者第二次仍然听不懂。听不懂的原因通常不是「听漏了」，而是**当前讲法与他的认知结构不匹配**（例如用严谨定义讲给需要直觉的人）。
2. **无限循环** —— 学习者始终不达标时循环永不退出，会话卡死，体验灾难。

因此「继续讲」必须是有**变化**的讲，且必须**保证收敛**。

## 决策

未达标时采取**两级收敛策略**：

**第一级 —— 换角度重讲（`action=reteach`）**

按固定序列取**尚未使用过**的讲解角度，而不是重复上一次：

```
intuition(直觉类比) → visual(图示) → example(实例推演)
→ contrast(对比辨析) → formal(严谨定义) → socratic(追问引导)
```

- 已试角度记在 `teach_angles_tried`，由工具保证不重复。
- `visual` 角度触发 `tool:image_gen` 生成示意图。

**第二级 —— 降级拆解（`action=split`）**

同一知识点重讲轮次达到 `max_reteach_rounds`（默认 3）仍不达标时，判定为**知识点颗粒度太粗**，而非学习者能力问题：

- 将该知识点拆成 2~4 个更小的子知识点（由 `skill:study_plan` 生成），插入原位置。
- 记录 `split_depth`，上限 `max_split_depth`（默认 2）防无限下钻。
- 触顶后转为「标记为已知薄弱点 → 跳过并写入错题本」，让计划能继续推进。

## 理由

- **「换角度」对应真实教学法**：同一个概念，对直觉型学习者用类比、对严谨型用定义、对视觉型用图示。这是私教相对录播课的核心价值。
- **「拆解」是正确归因**：反复讲不通，多半是前置概念缺失或颗粒度过粗。继续硬讲是沉没成本，拆小才是解法。
- **两级都有上界**，因此整个循环**必然收敛**：角度序列有限（6 个）→ 触发拆解；拆解有深度上限 → 转跳过。不存在「直到学会为止」字面意义上的死循环。
- **触顶后跳过而非卡死**：学习是长跑，允许带着标记继续前进，比在一个点上耗死更符合真实学习行为。薄弱点进错题本，后续可回补。

## 后果

**正面**
- 闭环有变化、有收敛保证，不会卡死。
- 讲法轮换与拆解过程写进 `history`，成为「为什么我在这卡住」的复盘材料。
- 拆解产生的子知识点自动继承父点位置，计划结构自洽。

**负面 / 代价**
- 每个知识点可能膨胀出子点，计划条目变多。
  - 缓解：`max_split_depth=2` + 触顶转跳过。
- 「跳过」意味着允许不完美地推进，可能与部分用户「必须彻底搞懂」的预期不符。
  - 缓解：跳过时明确告知用户，并把该点写入错题本与报告的「建议回补」区；用户可主动要求回头重学。

## 备选方案

| 方案 | 放弃原因 |
|---|---|
| 重复同一讲法直到学会 | 无效重复；不收敛，会话卡死 |
| 无上限换角度 | 角度只有 6 种，耗尽后必然退化回重复；仍不收敛 |
| 不达标即拆解 | 拆解成本高；首次没懂更可能是讲法不匹配，先换角度成本更低 |
| 不达标就跳过 | 违背「直到学会为止」的产品承诺，闭环形同虚设 |
